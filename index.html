Git Demystified in 60 Seconds

1

What is a Branch?

A branch is simply a sticky label pointing to a commit snapshot. When you branch, you create an isolated playground that doesn't touch your main codebase.

2

Why do Conflicts Happen?

When you and a teammate edit the exact same lines of code before merging, Git stops and asks: "Which line is right?" You just pick one or combine both!

3

What is Squashing?

Taking 5 small "WIP", "fixed typo", "trying again" commits and rolling them into 1 clean, professional commit for your GitHub Pull Request.

4

The Git Reflog Safety Net

Git never truly deletes commits immediately. Every single action is saved in the local reflog, so you can always time-travel backward.
